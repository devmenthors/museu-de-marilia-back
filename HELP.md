## Como arrumar o MinIO:
1. Peça uma [licença gratuita do MinIO](https://www.min.io/download/aistor-server?platform=linux)
2. Guarde essa licença dentro desse repositório em `/license` com o nome `minio.license` (ou mude o caminho no .env)
3. Atualize as credenciais de acesso no .env (MINIO_ACCESS_KEY_ID e MINIO_SECRET_ACCESS_KEY)
4. É só isso, agora é só fazer sail up normal
